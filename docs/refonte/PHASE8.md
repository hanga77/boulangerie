# Phase 8 — Reporting avancé

## Livré

| URL | Rôle |
|-----|------|
| `/cycle/reporting` | Écran synthèse + tableaux revenus/dépenses |
| `/cycle/reporting/synthese.csv` | CSV totaux + CA par source |
| `/cycle/reporting/depenses.csv` | CSV dépenses seule |
| `/cycle/reporting/export.csv` | CSV complet (synthèse + tous mouvements) |

Paramètres communs : `?debut=YYYY-MM-DD&fin=YYYY-MM-DD`

Rôles : ADMIN, MANAGER.

## Excel

- Séparateur `;` (`sep=;` en tête)
- Ouvrir avec Excel / LibreOffice Calc (UTF-8)

## Menu

Finance → **Reporting (export)**
